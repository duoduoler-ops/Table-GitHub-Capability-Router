# 虚构环境摘要（输入）

以下内容只用于演示，不代表任何真实设备。

- 模型可以直接根据用户提供的信息回答问题。
- `workspace-reader` 可以只读检查用户指定的工作区文件；本轮已验证读取成功。
- `local-shell` 可以运行本地命令，但本轮只允许只读检查；写入、删除、安装和配置修改需另行批准。
- `public-doc-search` 只能查询公开文档；本轮没有实际调用，健康状态未知。
- `site-publisher` 可能把内容发布到外部网站；当前未启用，也没有发布授权。
- 用户门禁：安装、登录、外发、删除、改配置必须先确认。
