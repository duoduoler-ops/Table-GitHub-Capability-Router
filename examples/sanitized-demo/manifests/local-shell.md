# 能力卡：local-shell

- 一句话说明：对用户指定的本地范围执行核查并返回可验证结果；不要用于未经批准的写入、删除、安装或配置修改。
- 类型：本地 CLI / Shell。
- 管理状态：`conditional`。
- 健康状态：`unverified`；演示输入只有能力声明，没有本轮命令成功证据。
- 风险：`medium`；命令边界不清时可能产生文件或配置副作用。
- 调用前检查：确认目标范围、命令只读、无需密钥、无需登录、无需管理员权限。
- 回退：改用 `workspace-reader`，或让用户手动执行并粘贴结果。
- 晋升条件：在隔离目录完成只读验证，并由人工复核证据。
- 回滚：本卡未启用任何配置，无需回滚。
